# Library Book Management API

## About the Project
This project is a REST API developed using Node.js and Express.js.
It is used to manage library book records.

## Features
- View all books
- Add a new book
- Search for a book by ID
- Update book details
- Delete a book
- Filter books by author

## Technologies Used
- Node.js
- Express.js
- JavaScript

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Run npm install.
4. Start the server using:

   node server.js

5. Open http://localhost:3000

## API Base URL
http://localhost:3000/api/books

## Port
3000
